and Bootstrap to showcase my skills, projects, education, experience, 
and professional achievements.

to explore my technical skills, projects, and career journey.

⚙️ Installation & Setup
1. Clone the Repository
git clone https://github.com/Rishabh-1585/professional-portfolio.git
2. Navigate to the Project Directory
cd professional-portfolio
3. Create a Virtual Environment
python -m venv venv
4. Activate the Virtual Environment

Windows:

venv\Scripts\activate
5. Install Dependencies
pip install django

If a requirements.txt file is available, use:

pip install -r requirements.txt
6. Apply Database Migrations
python manage.py migrate
7. Start the Development Server
python manage.py runserver

Open the following address in your browser:

http://127.0.0.1:8000/
